A project to analyze player sentiment in miHoYo community.
# 米游社玩家情绪分析项目

## 项目目标
分析米哈游旗下游戏《崩坏：星穹铁道》版本更新后，玩家在米游社社区的情绪变化与讨论焦点。

## 技术栈
- Python
- requests (网络请求)
- BeautifulSoup (HTML解析，当前使用)

## 项目进展日志

### 2025.01.21 - 首次尝试与问题发现
- **目标**：尝试爬取米游社“崩坏：星穹铁道”版块首页的帖子列表。
- **行动**：使用 `requests` 库获取页面，并用 `BeautifulSoup` 尝试解析。
- **遇到的问题**：获取到的HTML代码中不包含帖子列表内容，页面核心数据为JavaScript动态加载。
- **初步分析**：通过查看HTML结构，发现页面由前端框架渲染，直接解析静态HTML无效。
- **下一步计划**：
    1.  学习使用浏览器开发者工具分析动态加载的数据接口。
    2.  根据接口类型，调整爬虫策略。

## 待解决的问题
如何定位并获取米游社动态加载帖子的真实数据接口？
